# Спецификация форка

Цель: перенести в вырез то, что сейчас занимает место в верхней панели, и добавить инструменты для работы с агентами.

## Раскладка

- **Шапка открытого выреза, справа:** индикатор VPN (флаг и код страны) · кнопка Amphetamine · заряд батареи. Кнопки настроек нет — настройки открываются по ⌥⌘, (меняется в Настройки → Shortcuts).
- **Батарея** — только процент, цветом: зелёный при зарядке или от сети, жёлтый в режиме энергосбережения, красный при 20 % и ниже, иначе белый.
- **Вкладки:** Главная (музыка и календарь) · Полка · Фразы · Агенты.
- **Свёрнутый вырез:** уведомления агентов, обратный отсчёт до ближайшего события, музыка, работающие агенты — порядок см. F6.
- **Обновления Sparkle отключены**, чтобы релизы оригинального Boring Notch не заменили сборку форка.

## F1. Календарь из TickTick

- События берутся из системного «Календаря» через EventKit, как сейчас.
- TickTick подключается без кода: подписка на календарь в TickTick (Настройки → Календарь → Подписка на календарь), полученная ссылка `.ics` добавляется в «Календарь» → Файл → Новая подписка на календарь.
- **«Напоминания» удаляются полностью:**
  - запрос доступа к ним;
  - получение и отображение;
  - отметка выполненных;
  - настройка «Скрывать выполненные»;
  - строки в онбординге и настройках.
- Ограничения: подписка только для чтения и обновляется с задержкой. Частоту обновления задаёт «Календарь».

## F2. Обратный отсчёт до события

- Если до начала события меньше N минут (по умолчанию 15, настраивается), в свёрнутом вырезе показывается название события и «через 8 мин». В момент начала события — «сейчас».
- События на весь день не учитываются.
- Приоритет выше музыки, ниже системных HUD и уведомления о зарядке.
- Включается и выключается в настройках календаря.

## F3. Amphetamine

- Управление через AppleScript самого Amphetamine:
  - `start new session with options {duration:…, interval:…, displaySleepAllowed:…}`;
  - `end session`;
  - `session is active`.
- Кнопка в шапке: чашка кофе. Заливка показывает, активна ли сессия. Клик запускает бессрочную сессию или останавливает текущую.
- На вкладке «Агенты» — то же управление, плюс сессии на 1 и 3 часа.
- Статус опрашивается раз в 10 секунд, а также при открытии выреза и после каждого клика.
- Режим с закрытой крышкой работает через настройки самого Amphetamine (Amphetamine Enhancer → Closed-Display Mode).
- Если Amphetamine не установлен, кнопка скрыта.

## F4. VPN (Happ Plus)

- Happ Plus регистрируется как системное VPN-подключение (`scutil --nc list` → `"Happ Plus"`).
- Статус, подключение и отключение — через `scutil --nc status|start|stop "<name>"`. Это делает XPC-помощник, у которого нет песочницы.
- Статус — это то, что знает сама система, а не интерфейс Happ. Так рассинхрона не будет.
- **Страна** берётся из внешнего IP через `https://api.country.is/` при каждой смене статуса и раз в 5 минут. Показывается как флаг и код страны.
- В шапке: флаг и код страны, если подключено; перечёркнутый щит, если отключено. Клик подключает или отключает.
- Если подключение или отключение не удалось, плашка на 4 секунды краснеет и пишет «Couldn't connect» / «Couldn't disconnect»; повторный клик пробует снова.
- Имя VPN-подключения задаётся в настройках, по умолчанию «Happ Plus».

## F5. Вкладка «Фразы»

- Список пар «название → текст»: ссылки на соцсети, ФИО, почта и т. п. Хранится в `Defaults`.
- Во вкладке — сетка плашек. Клик копирует текст в буфер, на плашке на секунду появляется отметка «скопировано».
- Добавление, изменение, удаление и порядок — в разделе настроек «Фразы».

## F6. Статус агентов (Claude Code, Codex)

- **Транспорт.** Хук вызывает скрипт `fork/agent-hook.sh` из ресурсов приложения. Скрипт делает `open -g "boringnotch://agent?…"` и передаёт в ссылке источник, событие, ID сессии, папку, название чата и текущий инструмент.
- **Хуки.** У Claude они в `~/.claude/settings.json`, у Codex — в `~/.codex/hooks.json` (тот же формат; новые хуки нужно один раз одобрить в Codex).

  | Событие | Состояние |
  |---|---|
  | `UserPromptSubmit` | работает |
  | `PreToolUse` / `PostToolUse` | работает: heartbeat не чаще раза в 30 с, а после ожидания отправляется сразу |
  | `Stop` | закончил, с баннером |
  | `Interrupt` (Codex) | закончил, без баннера |
  | `Notification` / `PermissionRequest` | ждёт ответа (запрос разрешения создаёт сессию, даже если её не было) |
  | `SessionEnd` | сессия удаляется |

- **Название чата.** У Claude — название из десктопного приложения (если сессия оттуда), иначе запись `custom-title` в транскрипте, у Codex — `threads.name` из `~/.codex/state_5.sqlite`. Читается только при смене состояния.
- **Прерывание Claude.** Отдельного события у Claude нет, поэтому сессия «работает» без событий 15 минут считается законченной. На «ждёт» этот тайм-аут не действует.
- **Вкладка «Агенты».** Вид строки — см. «Единый вид статуса агента».
  - Клик открывает чат в десктопном приложении: `claude://code/continue?session=<local_… id десктопа>`; сессия Claude из терминала открывается через `claude://resume?session=<CLI id>` — десктоп импортирует её; Codex — `codex://threads/<id>`. Если ссылки нет, справа на 3 секунды появляется «No chat link».
  - Кнопка 📁 при наведении открывает папку; при ошибке — «Couldn't open folder».
- **Диагностика** в Настройки → Agents & Status: для Claude и Codex — есть ли хук в `~/.claude/settings.json` / `~/.codex/hooks.json` (проверяет XPC-помощник), когда пришло последнее событие с момента запуска; предупреждение, если приложение запущено не из `/Applications` (хуки ссылаются на скрипт оттуда).
- **Свёрнутый вырез.** Баннер «закончил» или «ждёт» с коротким именем — папкой проекта.

### Единый вид статуса агента

Все места (вкладка «Агенты», баннер и индикатор в свёрнутом вырезе, точка на обложке) берут текст, цвет и иконку из `fork/AgentStatus.swift`.

| Состояние | Цвет | Иконка | Текст |
|---|---|---|---|
| работает | синий | пульсирующая точка | что делает агент: «Running command», «Editing files», «Reading files», «Searching code», «Browsing the web», «Running subagent», «Planning», «Using <MCP-сервер>», иначе «Working» |
| ждёт | жёлтый | ⓘ | «Needs input» |
| закончил | зелёный | ✓ | «Done» |

- Инструменты Claude и Codex сводятся к одним и тем же действиям: `Bash`, `shell` и `exec_command` → «Running command»; `Edit`, `Write` и `apply_patch` → «Editing files» и т. д.
- Строка во вкладке: «Название чата — статус», где статус цветной. Перед ней крупный значок Claude/Codex (иконка приложения), под ней папка.
- Справа в строке — сколько длится текущее состояние: сколько агент работает (отсчёт с последнего сообщения), ждёт или сколько прошло с «Done». Формат компактный: `1h12m34s`, `12m3s`, `45s`. Нулевые часы и минуты, а также нулевые секунды при наличии часов или минут не пишутся. Тот же формат у оставшегося времени Amphetamine.
- Свёрнутый вырез, баннер и индикатор устроены одинаково: слева иконка и папка, справа цветной статус и значок Claude/Codex. Если работают несколько агентов, справа «N working» и значки всех работающих.
- Приоритет в свёрнутом вырезе: баннер агента («Done», «Needs input») на 3 секунды → ближайшее событие TickTick (если играет музыка, слева вместо точки календаря обложка трека) → музыка → работающие агенты (только без музыки; при музыке — синяя точка на обложке).

## F7. Автоматический Amphetamine

- Пока хотя бы одна сессия работает, приложение держит включённой сессию Amphetamine.
- Через 2 минуты после того, как работающих сессий не осталось, приложение её останавливает — но только если запускало её само.
- Признак «запущено для агентов» хранится в настройках и переживает перезапуск приложения. Ручную сессию приложение не трогает.
- Выключение переключателя «Auto while agents work» сразу останавливает сессию, запущенную для агентов.

## F8. Нагрузка на систему

- Во вкладке «Агенты»: загрузка CPU (по разнице `host_processor_info`) и занятая память (active + wired + compressed из `host_statistics64`). Обновление раз в 2 секунды, только пока вкладка открыта.
- Температура не показывается: доступ к SMC из песочницы закрыт.

## F9. Полка: путь к файлу

- Пункт «Скопировать путь» в контекстном меню виден всегда, а не только с ⌥.
- Новая настройка «Копировать путь при добавлении файла»: после перетаскивания файла на полку его путь сразу копируется в буфер.

## F10. Переключение вкладок

- Наведение на иконку вкладки: переключение через 150 мс, чтобы вкладки не мелькали, когда курсор проходит по шапке.
- Свайп двумя пальцами по трекпаду: пальцы влево — следующая вкладка, вправо — предыдущая. Один свайп — одна вкладка, по кругу не переходит.

## F11. Компактная «Главная» с календарём

- Если календарь включён, музыка сжимается в узкую колонку слева: обложка, строка «трек · исполнитель», полоса прогресса, кнопки «назад», «пауза», «вперёд».
- Шапка календаря в одну строку: «Mon, 26 Oct · today» и стрелки ‹ › по дням. Кнопка «Today» появляется, когда выбран другой день.
- Каждое событие занимает одну строку. У задач без времени время не показывается, у остальных — время начала.
- Если календарь выключен, остаётся полноразмерный плеер.

## F12. Мелкие улучшения

- Клик по задаче из подписки TickTick открывает приложение TickTick, а не «Календарь». Задача из TickTick определяется по слову «TickTick» в названии календаря, в аккаунте, ссылке или заметке события.
- Кнопка 📁 у сессии во вкладке «Агенты» открывает её рабочую папку через XPC-помощник: в Finder или в приложении, указанном в настройках. Клик по самой сессии открывает чат (см. F6).
- Пока агенты работают:
  - если музыка не играет и нет события, в свёрнутом вырезе — синяя точка, папка, текущее действие (или «N working») и значки агентов;
  - если играет — пульсирующая синяя точка на обложке.

## F13. Горячая клавиша для «Фраз»

- ⌃⌘V открывает вырез сразу на вкладке «Фразы». Если курсор не наведён на вырез, через 6 секунд он закрывается.
- Клавишу можно поменять в Настройки → Snippets.

## F14. Локальные dev-серверы

- Во вкладке «Агенты», раздел «Servers»: TCP-порты от 1024 и выше, которые слушают процессы текущего пользователя. Список составляет XPC-помощник через `lsof`.
- Показываются только dev-процессы. Исключаются программы из `/Applications`, `~/Applications`, `~/Library`, `/System`, `/Library` и других системных путей, кроме Xcode и Command Line Tools. Поэтому туннель VPN, Raycast и системные службы в список не попадают.
- Клик открывает `http://localhost:<port>`. Кнопка ⏹ отправляет процессу SIGTERM — помощник делает это, только если процесс всё ещё проходит фильтр. Если остановить не удалось, в строке на 3 секунды появляется «Couldn't stop».

## R1. Ревью Codex (26.10.2026): что принято

| Пункт | Решение |
|---|---|
| R1.1 разбор JSON в хуке | Принято. Поля берутся через встроенный `plutil -extract <поле> raw` — только корневые, кавычки и Unicode не портятся, невалидный JSON молча пропускается. Отдельный исполняемый файл не нужен. Экранированный `\u0000`, который `plutil` не понимает, вырезается заранее. |
| R1.2 Amphetamine при выключении автоматики | Принято. Выключение переключателя сразу останавливает сессию, которую запустило приложение; ручную не трогает. Повторные события не ставят второй запуск, пока первый выполняется. Ошибка AppleScript при опросе статуса не считается «сессия выключена» и не сбрасывает признак владения. Распознавание ручной замены автоматической сессии в самом Amphetamine — не делаем. |
| R1.3 тайм-аут ожидания | Принято частично. 15 минут без событий применяются только к «работает»; «ждёт» держится до следующего события. Отдельное состояние «нет обновлений» не вводим: устаревшая сессия по-прежнему становится «Done». |
| R1.4 запрос разрешения после перезапуска | Принято. `PermissionRequest` (Codex) и `Notification` с `notification_type = permission_prompt` (Claude) создают ожидающую сессию, даже если приложение её раньше не видело. Остальные уведомления меняют только уже идущую сессию. |
| R1.5 обновление календаря | Принято. При изменении EventKit обновляется и список выбранного дня; ответ для дня, с которого уже ушли, отбрасывается. Смена выбранных календарей обновляет и обратный отсчёт. |
| R1.6 автопрокрутка | Принято. Настройка «Auto scroll to next event» теперь работает; фоновая синхронизация не сбрасывает ручную прокрутку — прокрутка только при другом наборе событий (другой день). |
| R1.7 диагностика, ошибки, тесты | Диагностика хуков и видимые ошибки (VPN, папка, чат, dev-сервер) — сделаны, см. F4, F6, F14. Автотесты отложены: нужен отдельный test target. |

Попутно исправлено: клик по сессии Claude не открывал чат — десктопный Claude принимает свой ID сессии (`local_…`), а не ID из хука. Хук один раз на сессию находит его в `~/Library/Application Support/Claude/claude-code-sessions` (поле `cliSessionId`) и передаёт в ссылке; оттуда же берётся название чата, как в сайдбаре Claude. Сессии, запущенные из терминала, открываются через `claude://resume?session=<CLI id>`.
